# Marco Falanga

**ML Engineer · Edge AI & Embedded Software**

I'm a machine learning engineer with an M.Sc. in Computer Engineering (Artificial Intelligence & Robotics) from the University of Padova.
I have shipped quantized, continually-learning vision models to CPU-only embedded hardware in production, built a tested, containerized LLM agent service, and verified safety-critical avionics software under DO-178C.
I take models onto real hardware and make AI systems measurable, testable and reliable.

This site collects documentation and demos of my projects, from university courses and my theses to work and personal projects.
The code of most projects is private; each page explains what the project does, how it was built and what came out of it.
